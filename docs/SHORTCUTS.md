# 鼠标与快捷键速查

[返回首页](../README.md) · [完整操作手册](USER_GUIDE.md)

以下画布快捷键在时间轴获得焦点时生效。Windows / Linux 使用 Ctrl；代码对选择、复制、粘贴和撤销支持 macOS 的 Command 修饰键，macOS 尚未完成同等验收。标题、备注等输入框保持正常文字编辑行为。

| 操作 | 方法 |
|---|---|
| 打开时间轴 | 点击侧栏时钟图标，或命令面板搜索「打开演示脚本时间轴」 |
| 选中一个动作 | 单击动作 |
| 加选 / 取消某个动作 | Ctrl+单击；Shift+单击可加选 |
| 框选多个动作 | 在泳道空白处按住拖框，支持反向拖框 |
| 保留原选择并框选 | Ctrl 或 Shift+拖框 |
| 全选可见动作 | Ctrl+A |
| 取消选择 / 连线 / 拖动 | Esc；单击空白可清除选择与连线预览 |
| 新建动作并输入标题 | 双击泳道空白处 |
| 修改动作标题 | 双击动作 |
| 修改动作详情 | 右键动作 → 编辑详情；或选中后点底部「编辑详情」 |
| 提交标题 / 项目名称 | Enter 或点击输入框以外区域 |
| 取消本次文字修改 | Esc；中文输入法确认不会提前提交 |
| 移动动作 | 按住动作中央拖动，横向改时间，纵向改泳道 |
| 整体移动多选动作 | 按住任一所选动作中央拖动 |
| 调整持续时间 | 拖动动作两端；多选时拖选框两端或所选动作边缘，等比例调整 |
| 复制所选动作 | Ctrl+C；或动作右键菜单 → 复制动作 / 复制所选动作 |
| 在鼠标位置粘贴 | 鼠标停在目标泳道与时间位置，Ctrl+V |
| 删除所选动作 / 连线 | Delete，直接删除；Ctrl+Z 可恢复 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z；或工具栏按钮 |
| 新建连接 | 按住动作节点拖至另一动作的相应节点 |
| 编辑连线文字 | 双击连线；也可右键选择「编辑文字标注」 |
| 关键标记 | 右键 → 标记为关键动作；或底部星标按钮，支持批量 |
| 调整缩放 | 工具栏 + / −、显示设置；Ctrl+滚轮 |
| 查看完整时间轴 | 工具栏「适应窗口」 |
| 移动泳道 / 分组 | 拖动名称左侧 `⠿` 手柄，按插入线定位 |
| 调整人员 / 设备列宽 | 拖动左栏标题右侧分隔线 |
| 恢复默认列宽 | 双击分隔线，恢复 182 像素 |
| 键盘调整列宽 | 分隔线获得焦点后用左右箭头，Shift 加快；Home / End 到最小 / 最大值 |

Delete 的直接删除仅作用于画布当前选择；输入框中的 Delete 删除文字。右键菜单和底部删除按钮保留确认。折叠分组会取消其中隐藏动作的选择。

Ctrl+C/V 保留所选动作的相对布局及内部关系；普通文本不会创建动作。粘贴时鼠标必须位于可见泳道，详情见 [复制与粘贴](USER_GUIDE.md#clipboard)。
