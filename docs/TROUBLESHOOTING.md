# 常见问题与故障处理

[返回首页](../README.md) · [安装指南](INSTALLATION.md) · [操作手册](USER_GUIDE.md)

## 插件列表中找不到 CueFlow

检查当前打开的是安装时选择的知识库；确认 `.obsidian/plugins/cueflow-timeline/` 内直接包含三份同版本文件，没有嵌套第二层文件夹。重启 Obsidian，在第三方插件设置中启用。GitHub 的 Source code ZIP 需要自行定位运行文件，普通用户使用命名的插件安装包。

## 看不到项目，或切换保存目录后原项目消失

默认项目目录是知识库内的 `CueFlow/`，可在插件设置查看。修改保存目录不会移动原文件；将目录切回原值，或备份后自行搬迁项目。每份项目需包含一个合法 `cueflow` JSON 代码块。正文可以自由编辑，代码块里的 ID 和引用需有效。

## 改项目名称后，Markdown 文件名仍是旧名字

这是当前行为：修改的是项目显示名称，下拉菜单读取这个名称；文件路径保持。需要改文件名时，在 Obsidian 文件列表中操作，再重新打开项目。

## 双击为什么只改标题，没有打开详情

双击动作用于原位改标题；右键 →「编辑详情」，或选中动作后点底部「编辑详情」。双击泳道空白用于创建新动作。Enter / 失焦保存标题，Esc 取消修改。

## 动作拖动不够精细，或找不到远处动作

吸附设为 1 秒，放大至 600–900 px/分后微调；「适应窗口」查看全场。必要时增加总时长，或先切换紧凑显示、折叠无关分组。参考虚线只提醒对齐，不额外改变吸附规则。

## 动作重叠变红，是否会阻止执行

同泳道的非零时长动作重叠显示红色虚线提示，仍可保存；插件不执行设备控制。请检查同一人员/设备是否能并行处理，必要时调整时间或资源。里程碑不作为时长占用。

## 为什么连不上线

先移入或选中动作，让节点亮起。右左建立前后依赖，左左同时开始，右右同时结束，上下节点之间建立关联。自连、重复同步、循环依赖、矛盾同步、超过 24 小时等情况会被拒绝。松开位置必须在目标节点，Esc 会取消。

若同时开始与前后依赖冲突，删除不需要的关系，或调整排程。关闭「依赖顺延」只关闭前后依赖的自动推后，**同时开始/结束仍生效**。

## 为何修改一个动作，其他动作也移动

存在同步线时相关动作保持同时开始/结束；启用依赖顺延时，受冲突影响的后续动作会推后。检查相关连线与动作详情。整体移动/拉伸若无法在保持相对布局时满足约束，会拒绝本次操作。

## 连线被动作遮住，如何操作

长连接的竖段允许从动作下方穿过，遮挡区响应动作。单击可见线段选中，双击可见线段改标注；也可打开相关动作详情查看关系。短线可放大时间轴查看。连线默认无文字，需要时双击添加。

## Ctrl+C/V 没有生成动作

先选中动作并让画布获得焦点；复制后将鼠标停在可见泳道的时间区域，再按 Ctrl+V。不要停在组标题、时间刻度、左侧名称列或画布外。在标题/备注输入框内，快捷键编辑文字。普通文本不会创建动作；目标可见泳道不足时先增加或展开泳道。

多动作粘贴按最早起点与最上方泳道定位；靠近底部/24 小时边界时会向内调整，保留相对布局。只复制所选动作内部关系，外部关系被移除是设计行为。

## 删除是否可以恢复

画布 Delete 直接删除当前选择，无弹窗；Ctrl+Z 恢复。多选删除会清理相关连接，并可一次恢复。撤销历史最多 60 次快照，仅在当前视图存在；关闭视图后请使用项目备份。

## 「未保存」或外部修改冲突怎么办

先用「保存为副本」保留当前编辑；检查项目目录是否可写、磁盘是否有空间，以及是否有其他编辑器或同步服务同时改动同一排程块。写入条件恢复后重试；如要采用磁盘版本，先保留当前修改，再点「重新读取」。避免反复在多个视图编辑同一项目。代码块外正文编辑可以共存，排程块冲突不会自动合并。

## AI 返回文件无法导入

要求 AI 返回完整 JSON 或只含一个 `cueflow` 数据块的 Markdown；不要只返回 CSV、建议或部分动作。检查 JSON 语法、项目版本、唯一 ID、资源引用、循环依赖、同步矛盾和时间范围。当前包格式为 `cueflow.project` / 1，项目数据格式为 5。文件上限 5 MB，另有动作/泳道/关系数量限制。

使用 [完整示例](../examples/AI优化项目.cueflow.json) 对照，并在预览中核对变化。无效文件不会部分合并到原项目；导入成功后也会保存为新项目。

## CSV / SVG 可以完整回导吗

CSV 是排程表，SVG 是图形交付文件；完整可编辑交换请用 JSON / Markdown。SVG 包含当前折叠分组中的动作，连线位于不透明卡片下方。导出位置是当前项目目录。

## 大项目变慢怎么办

优先紧凑显示，折叠无关分组，并按场次或章节拆分项目，减少密集连线。导入数量上限是输入保护，不是性能承诺。此前基础验收覆盖 300 动作 / 20 泳道；1000 动作仅作探索测试，v0.10.0 没有重跑完整压力测试。

## 如何反馈问题

在 [GitHub Issues](https://github.com/dzdanielzhang-rgb/CueFlow/issues/new/choose) 选择问题模板，提供插件 / Obsidian / 系统版本、最短复现步骤、预期与实际结果；必要时附截图和脱敏后的最小项目。先备份受影响文件，移除个人路径、项目机密与不需要分享的备注。可查看 [验收范围](VALIDATION.md) 判断环境差异。
