## 1. 认识项目、分组、泳道与动作

| 名称 | 作用 | 例子 |
|---|---|---|
| 项目 | 一份完整排程，保存为一个 Markdown 文件 | 发布会演示方案 |
| 分组 | 将人员或设备归类 | 导播组、飞手组、无人机组 |
| 泳道 | 一个执行人员、设备或资源，占时间轴的一行 | 导播、飞手 A、无人机 1 |
| 动作 | 某资源在指定时间执行的工作 | 开场画面、起飞、搜索、收尾 |
| 连接 | 表达动作间的顺序、同步或关联 | 组网确认后开始搜索 |

横轴是相对开始时间，从 **T+00:00** 起算。`03:12` 表示 3 分 12 秒；`01:30:00` 表示 1 小时 30 分。时间精度为整数秒。

<a id="projects"></a>
## 2. 创建、切换与命名项目

点击侧栏时钟图标，或通过命令面板打开「CueFlow Timeline: 打开演示脚本时间轴」。首次打开会在默认 `CueFlow/` 目录生成演示项目。

- 点击「+ 项目」，填写名称，创建新方案。
- 顶部项目选择区域可直接修改当前项目名称。Enter 或失焦保存；Esc 取消本次名称修改。右侧下拉箭头用于切换项目。
- 「项目设置」可同时修改名称与总时长，支持撤销/重做。
- 下拉选项显示项目数据里的实际名称；同名项目附路径帮助区分。
- 修改项目显示名称会保留原 Markdown 文件名。需要修改文件名时，可在 Obsidian 文件列表中操作，并在时间轴重新打开该项目。

切换或关闭前确认右下角为「已保存」。项目目录可在「设置 → CueFlow Timeline → 项目保存目录」修改；原有文件不会自动搬迁。

## 3. 设置时间轴与显示

### 总时长

点击工具栏「总时长」，或「显示设置 → 时间轴总时长」。输入 `30:15`、`01:30:00` 等时间，也可点击 `+1 / +5 / +10 分钟`。保存后更新时间轴范围、适应窗口、排练终点和 SVG 导出，支持撤销。

总时长范围为 1 分钟至 24 小时。缩短时不能早于最后一个动作的结束；动作超出原范围时会自动扩展项目时长。动作结束不得超过 24 小时。

### 缩放、吸附与紧凑显示

| 设置 | 入口与效果 |
|---|---|
| 缩放 | 工具栏 + / −、Ctrl+滚轮或「显示设置」；「适应窗口」查看全场 |
| 吸附 | 工具栏选择 1 / 5 / 10 / 30 / 60 秒；拖动按相应步长调整 |
| 逐秒微调 | 吸附选 1 秒，缩放建议 600–900 px/分 |
| 人员/设备显示 | 工具栏或「显示设置」切换标准 / 紧凑，泳道高度分别为 74 / 40 像素 |
| 左栏宽度 | 拖动人员/设备标题右侧分隔线，范围 160–600 像素；双击恢复 182 像素 |

缩放和紧凑模式只改变显示，不改变排程时间。偏好会保存。分隔线获得焦点后，可用左右方向键调整列宽，Shift 加快，Home / End 设为最小 / 最大值。

**怎样选择**：整场看不全，用「适应窗口」或缩小；需要精确移动 1 秒，放大并选 1 秒吸附；人员行太多，用紧凑显示；名称显示不全，拖宽左栏；需要增加整场范围，改总时长。这些操作都不会把现有动作时长等比例放大。

## 4. 组织分组与泳道

点击「+ 分组」创建自定义分组；点击分组名可折叠或展开，右侧「⋯」可改名、排序、添加泳道或删除分组。删除分组后，泳道及动作保留并进入「未分组」。系统「未分组」区域固定在末尾。

点击「+ 泳道」，填写名称并选择分组；分组右侧的「+」会预选该分组。空名称不能创建，取消不会生成泳道。双击泳道名称，或点击「⋯ → 编辑名称 / 分组 / 颜色」，可修改名称、归属与颜色。只能直接删除空泳道；已有动作时先移动或删除其中动作。

### 拖动排序与跨组移动

- **泳道**：按住名称左侧 `⠿` 手柄上下拖动，插入线显示位置。拖到其他组内可指定顺序；拖到组标题会进入该组末尾，空组和折叠组也可作为目标。
- **分组**：按住分组左侧 `⠿` 拖动，整组的泳道与动作一起移动；组内顺序保持。
- 按 Esc 取消拖动；松开后保存，支持一次撤销。排序和分组归属变化不改变动作时间、ID 或连接对象。

折叠分组会取消该组隐藏动作的选中状态，避免批量操作到不可见内容。SVG 导出包含折叠组中的泳道和动作。

例如把「飞手 A」从「飞手组」拖到「现场执行组」，改变的是资源分类与显示位置，原动作仍属于该泳道，时间和连接对象保持。要让两个动作同时开始，需要建立左左同步线，放在同一分组本身没有同步效果。

<a id="actions"></a>
## 5. 创建、编辑与移动动作

### 创建与命名

双击泳道空白处，在该位置创建动作，并直接输入标题。默认持续 60 秒，接近 24 小时边界时会缩短。Enter 或失焦保存标题；Esc 放弃本次名称修改并保留「新动作」。也可点击顶部「+ 动作」或泳道右侧「+」，在详情窗口填写信息。

### 选择与编辑

- 单击动作仅选中；单击空白或按 Esc 清除选择与未完成连线预览。
- 双击动作直接修改标题，支持中文输入；输入法确认不会提前提交。
- 右键动作 →「编辑详情」，或选中后点击底部「编辑详情」，可修改标题、泳道、开始、持续时间、状态、备注、关键标记、前置动作与已有连线标注等。
- 详情窗口保存才应用本次修改，取消保留原内容。

### 移动与拉伸

按住动作中央拖动：横向修改开始时间，纵向改泳道；拖动两端手柄调整时长。拖动时接近其他动作的开始/结束时间，会显示竖向虚线及「接近 / 对齐」提示；跨泳道时显示目标泳道横线。参考线提供视觉提醒，时间仍遵循吸附步长。

Esc 或取消拖动会还原预览。轻微点击抖动不会更改动作。开启依赖顺延时，拖动可能影响后续动作；存在同步线时，相关动作也会按同步约束调整。

**结果示例**（无其他约束）：原动作为 30–50 秒，持续 20 秒。中央向右移动 10 秒后为 40–60 秒；只拉右边缘增加 10 秒后为 30–60 秒。前者保留时长，后者保留起点。

### 删除

选中动作后按 Delete 直接删除，无确认弹窗，同时清理相关依赖、同步、关联和标注；Ctrl+Z 可恢复。右键菜单和底部删除按钮保留确认。输入框中的 Delete 只删除文字。

## 6. 框选与批量调整

在泳道空白处按住并拖出矩形，接触选框的动作会被选中，支持反向拖框。Ctrl+单击可加选或取消单个动作；Shift+单击可加选；Ctrl / Shift+拖框保留原选择并增加动作。Ctrl+A 选中所有可见动作。

选中多个动作后：

- **整体移动**：拖动任一所选动作中央，统一改变开始时间；上下拖动可整体跨泳道移动，保持相对时间和泳道间隔。
- **等比例拉伸**：拖动整体选框两端的手柄，或所选动作的边缘，固定另一端，按比例改变选中动作的起点、时长及内部间隔。
- 非零动作最短 1 秒，里程碑保持零时长。边界会限制整体调整。
- 一次批量操作对应一次撤销；Esc 取消预览。Delete 可删除全部所选动作。

连接对象保持。依赖顺延可能推后未选中的后续动作；同步约束持续生效。若约束使相对布局无法保持，本次整体操作会被拒绝；可将相关前置/中间动作一并选中，或按需要关闭前后依赖顺延。关闭顺延不会关闭同步关系。

**移动与拉伸的区别**：A 为 30–50 秒、B 为 60–80 秒，整体后移 60 秒后变为 90–110 秒和 120–140 秒；如果固定选框左端，把整体跨度从 50 秒拉到 100 秒，则变为 30–70 秒和 90–130 秒，内部 10 秒空隙也放大为 20 秒。此例假设没有其他约束，实际按整数秒取整。

## 7. 连接、同步与标注

鼠标移入或选中动作时，上下左右四个节点亮起；移开且未选中时隐藏。按住一个节点，拖至另一动作相应节点，松开创建连接；拖动时实时预览，Esc 或无效落点会取消。

| 连接 | 语义 | 显示 |
|---|---|---|
| A 右 → B 左 | B 不早于 A 结束后开始 | 实线、单端箭头 |
| B 左 → A 右 | 与上一行相同，反向拖线仍识别 A 为前置 | 实线、单端箭头 |
| A 左 ↔ B 左 | 两动作开始时间相同 | 橙色、双端菱形 |
| A 右 ↔ B 右 | 两动作结束时间相同，可有不同时长 | 橙色、双端菱形 |
| 上/下 → 上/下 | 从起拖动作指向目标动作的关联/目标 | 虚线、单端箭头 |

### 前后依赖与自动顺延

工具栏「依赖顺延 ✓」表示启用；切换为「手动排期」后，前后依赖不自动推后。开启时，当后续动作早于前置结束，会顺延后续及相关动作；前置提前不会自动把所有后续动作拉早。前后依赖不得形成循环。

例如 A 为 0–30 秒、B 为 30–90 秒且依赖 A：将 A 的时长改为 50 秒，开启顺延时 B 改为 50–110 秒；手动排期时 B 仍为 30–90 秒，需要人工处理冲突。依赖只要求不早于前置完成，并不强制无缝紧接。

### 同时开始与同时结束

新建同步线时，优先以**起拖动作**的时间对齐另一动作；如果会产生负开始时间，则整体推后到合法位置。之后拖动或在详情修改任一动作时，关联动作继续满足同时开始或结束。

同步约束始终生效，包括「手动排期」模式。相互矛盾的同步环、无法与启用的前后依赖同时满足的约束，或超过 24 小时的调整会被拒绝，原项目保持。例如两个正时长动作既要求同时开始，又要求其中一个在另一个完成后开始，开启依赖顺延时无法同时满足。

**同步结果示例**：A 为 30–50 秒、B 为 80–120 秒，且没有其他约束。从 A 左节点连到 B 左节点，B 改为 30–70 秒；从 A 右节点连到 B 右节点，B 改为 10–50 秒。同步修改开始位置以对齐对应端点，不会把两个动作强制改成相同时长。上下关联线则不改变这两段时间。

### 连线标注与删除

连线默认不显示文字。双击连线输入标注，可修改或清空；也可右键选择「编辑文字标注」。标注只解释关系，不改变约束。动作详情可编辑相关标注并移除同步关系；单击连线选中后按 Delete 删除，Ctrl+Z 恢复。

### 密集排程中的线路

紧邻动作使用短线和自适应箭头；没有间隙时，动作外侧显示小弯桥。长连接允许竖段从不透明动作下方穿过，横段优先避让动作。连线带背景描边和较宽点击区域；卡片覆盖处仍优先响应动作操作。选中动作会突出相关线，SVG 导出保留同样的遮挡层级。

## 8. 复制与鼠标位置粘贴

1. 选中一个动作，或框选多个动作。
2. 按 Ctrl+C，或右键选择「复制动作 / 复制所选动作」。
3. 将鼠标移到**可见泳道**的目标时间位置，按 Ctrl+V。
4. 新动作出现并被选中，可继续整体移动或拉伸。

鼠标位置对应所复制动作中**最早的起点**及**最上方泳道**。复制保留标题、时长、备注、状态、关键标记、相对时间与泳道间隔，并为动作和连线生成新 ID。

只保留所选动作之间的依赖、同步、关联和标注。指向未选中动作的关系不复制，原动作也不修改。重复粘贴会创建独立副本，一次 Ctrl+Z 撤销整次粘贴。

**片段示例**：原关系是 X → A → B，只复制 A（30–50 秒）和 B（60–80 秒），鼠标放在 180 秒粘贴，得到 A′（180–200 秒）和 B′（210–230 秒）。A′ → B′ 保留，X → A′ 不存在；副本间的 10 秒间隔保持。

靠近底部泳道或 24 小时终点时，整体向内调整以保持相对布局并提示；泳道总数不足则拒绝粘贴，请先增加泳道。鼠标位于左侧名称列、组标题、时间刻度或画布外时无法粘贴。

输入框内仍是普通文字复制粘贴；普通文本不会创建动作。跨项目粘贴时，需要目标项目具有足够的可见泳道。

## 9. 关键动作、里程碑与状态

- **关键动作**：选中后点底部「☆ 标为关键动作」，或右键「标记为关键动作」。支持单个/批量添加和取消，详情也可修改。金色星标不改变时长和依赖。
- **里程碑**：在详情将持续时间设为 `00:00`，或右键「设为里程碑」，呈现菱形。可用于开场点、幕间确认、收尾等；也能标为关键动作。
- **状态**：详情中选择 planned / active / done（计划、进行、完成），右键可切换完成状态。它们是人工记录，不会发出设备指令。
- **同泳道重叠**：非零动作时间重叠时显示红色虚线边框，仅提示复核，不阻止排程。零时长里程碑不计为占用时长。

星标与状态保存到项目；CSV 包含关键标记，SVG 显示星标。

关键星标不会锁定时间，也不会自动改变调度优先级。需要 AI 保持关键动作时间时，应在优化目标明确提出。排练计时用于提示当前执行位置，动作的完成状态仍由用户记录。

## 10. 排练、保存与恢复

### 排练

点击「▶ 排练」启动相对计时，红色进度线显示当前时间，正在执行的动作高亮。暂停后可继续，点击「↺ 归零」从头开始。排练用于人工核对流程，不会连接或控制无人机、灯光等设备。

### 自动保存与撤销

每份项目保存在知识库 Markdown 文件的唯一 `cueflow` JSON 代码块内，代码块外可写导演备注。修改后自动保存，右下角显示「待保存 / 已保存」；Ctrl+Z / Ctrl+Shift+Z 撤销或重做，最多保留 60 次快照，关闭视图后不保留历史。

### 保存失败或冲突

如果排程块被其他窗口修改，或磁盘写入失败，显示「未保存」并提供：

| 选项 | 使用时机 |
|---|---|
| 重试保存 | 写入条件恢复后再次保存；实际数据冲突需先处理 |
| 保存为副本 | 保留当前视图的编辑结果，稍后与磁盘版本比较 |
| 重新读取 | 采用磁盘上的最新内容，先确认当前未保存修改已另行保留 |

代码块外的正文编辑可以与排程保存共存；同一排程块发生外部修改时不会静默覆盖。关闭未保存视图会尝试创建恢复副本，但磁盘不可写时仍可能失败。正式执行前确认已保存，并备份实际项目文件。

## 11. 文件交换与 AI 优化

| 格式 | 入口 | 适用场景 |
|---|---|---|
| 完整 JSON / Markdown | 导入 / 导出 → 导出完整项目 / AI 优化文件 | 继续编辑、备份交换、外部 AI 优化 |
| 完整文件导入 | 导入 / 导出 → 导入项目文件，或粘贴 AI 返回的项目 | 导入新方案，预览变化后保存为新项目 |
| CSV | 导出 CSV | 表格排程、交接、人工检查 |
| SVG | 导出 SVG | 矢量时间轴、演示文稿与分享 |

完整文件保留资源、动作、全部关系、标注、关键标记及项目正文。导入支持 JSON 项目包、裸项目 JSON、原生 cueflow Markdown；预览后另存为新项目，保留原方案。导入上限为 5 MB / 3000 动作 / 500 泳道 / 关联与同步连线合计 10000 条。

AI 流程：导出时填写优化目标 → 将文件交给外部 AI → 要求返回完整结构 → 导入查看动作、时间、依赖、同步、资源与关键标记变化 → 确认后保存为新项目 → 人工排练。内置导入校验不能代替业务可行性判断。

详细格式、完整示例和可复制提示词见 [项目文件与 AI 优化](PROJECT_FILES.md)。导出包含项目正文，交给外部工具前可自行检查内容。

## 12. 用一个小方案练习

1. 新建「开场练习」项目，总时长设为 `05:00`；创建「执行人员」「设备」两组，以及「导播」「飞手」「无人机」三个泳道。
2. 创建「开场画面」（导播，0 秒开始、20 秒）和「组网确认」（飞手，0 秒开始、30 秒）；用左左连线，使二者同时开始。
3. 创建「搜索演示」（无人机，30 秒开始、60 秒）；将「组网确认」右节点连到它的左节点。开启依赖顺延后，若组网推迟，搜索随之推后。
4. 创建「画面讲解」（导播，40 秒开始、50 秒），右右连接到「搜索演示」，使二者同时结束；试着改动讲解的时长，观察同步调整。
5. 从「搜索演示」下节点连接到「画面讲解」上节点，表达内容关联；双击这条线标注「讲解对应搜索画面」。
6. 框选「搜索演示」与「画面讲解」，Ctrl+C，将鼠标移到后半段时间，Ctrl+V。副本保留这两个动作内部的同步与关联，不带与原「组网确认」的外部依赖。
7. 为搜索动作添加关键星标；点击排练核对节奏，等待保存，再分别导出 JSON、CSV 和 SVG。

完成后可尝试整体移动、比例拉伸、泳道跨组拖动，并用 Ctrl+Z 恢复。有关失败提示见 [常见问题](TROUBLESHOOTING.md)。
