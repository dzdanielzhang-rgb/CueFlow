# CueFlow Timeline v0.10.0

面向 Obsidian 桌面端的秒级演示流程编排插件，适合发布会、舞台执行、多角色和多设备演示。

## 下载与安装

从 [本版本 Release](https://github.com/dzdanielzhang-rgb/CueFlow/releases/tag/0.10.0) 的 Assets 下载 **cueflow-plugin-v0.10.0.zip**，解压后将 `cueflow-timeline` 文件夹放入 `<知识库>/.obsidian/plugins/`。重启 Obsidian 并启用插件，用侧栏时钟图标或命令「打开演示脚本时间轴」进入。

也提供独立的 `main.js`、`manifest.json`、`styles.css` 与 `SHA256SUMS.txt`。三份运行文件须使用同一版本。[详细安装指南](../INSTALLATION.md) · [完整操作手册](../USER_GUIDE.md) · [快捷键](../SHORTCUTS.md)

## 本版本改进

- **近距离连线**：相邻动作使用自适应短线；没有间隙时采用小弯桥，改善箭头可见性。
- **同步关系**：左左连接表示同时开始，右右连接表示同时结束；橙色双端菱形区分同步，拖动和时长修改继续保持约束。
- **跨动作连线**：竖段允许从不透明动作下方穿过，横段优先避让；SVG 导出保留相同层级。
- **鼠标位置粘贴**：选中一个或多个动作 Ctrl+C，鼠标停在目标泳道与时间位置 Ctrl+V。保留相对时间、泳道间隔和内部依赖/同步/关联/标注，不带外部关系；一次撤销恢复。
- **完整公开文档**：项目首页、安装升级、操作手册、快捷键、AI 工作流、故障处理、贡献与维护发布说明。

保留已有分组/泳道拖动、多选批量移动与拉伸、关键星标、动作标题编辑、详情、对齐参考线、排练时钟、文件导入导出与保存冲突处理。

## 兼容性与升级

- 插件 0.10.0；manifest 声明最低 Obsidian 1.5.0，实测 Windows / Obsidian 1.14.4。
- 桌面端；macOS / Linux 未完成同等客户端验收，移动端不支持。
- 项目数据格式 **5**，可读取旧项目；可移植包仍为 `cueflow.project` / 1。
- 升级前备份实际项目目录和旧插件目录。回退到 0.9.1 或更早版本时，两者一起恢复。
- 同步关系即使关闭依赖顺延也生效；矛盾约束或超出 24 小时的调整会拒绝。
