# CueFlow Timeline

**在 Obsidian 中编排一场演示：把人员、设备、动作与依赖关系放到同一条秒级时间轴上。**

CueFlow 是面向发布会、舞台执行、多设备演示和 Run of Show 的桌面插件。通过泳道组织资源，拖动安排动作，用连线表达前后依赖、同时开始、同时结束或关联目标。项目保存在知识库的 Markdown 文件中，支持完整 JSON / Markdown 导入导出，也可交给外部 AI 优化后回导。

## 适合用来做什么

- **发布会与舞台执行**：编排主持、画面、灯光、场控等角色，按相对时间排练。
- **无人机与多设备演示**：分组管理飞手、无人机、地面设备，标明执行顺序与同步节点。
- **方案讨论与交付**：用 SVG 分享时间轴，用 CSV 查看排程，用完整项目文件交换可继续编辑的方案。

插件在本地运行，无需注册账户、API Key、npm 或其他任务插件。AI 优化通过用户自行选择的外部工具完成，插件负责文件交换、约束检查和变化预览。

## 五分钟开始

1. 从 [Release](https://github.com/dzdanielzhang-rgb/CueFlow/releases/tag/0.10.0) 下载 `cueflow-plugin-v0.10.0.zip`，解压到 `<知识库>/.obsidian/plugins/`。
2. 确认最终目录为 `.obsidian/plugins/cueflow-timeline/`，其中直接包含 `main.js`、`manifest.json`、`styles.css`；重启 Obsidian 并启用插件。
3. 点击侧栏时钟图标，或在命令面板搜索「打开演示脚本时间轴」。首次打开会生成演示项目。
4. 用「+ 项目」「+ 分组」「+ 泳道」建立自己的方案。双击泳道空白处创建动作并直接输入标题。
5. 拖动动作调整时间与泳道，拖动边缘调整时长；从动作节点拖线建立依赖或同步关系。
6. 点击「▶ 排练」核对执行节奏，通过「导入 / 导出」保存完整交换文件，或导出 CSV / SVG。

详细目录结构、升级与回退步骤见 [安装指南](docs/INSTALLATION.md)。GitHub 自动提供的 **Source code** 压缩包用于查看源码；普通用户下载上面命名的插件安装包。

## 功能一览

| 功能 | 操作与效果 |
|---|---|
| 秒级时间轴 | 相对时间从 T+00:00 开始；1 / 5 / 10 / 30 / 60 秒吸附；项目总时长 1 分钟至 24 小时 |
| 缩放与紧凑显示 | 加减按钮、Ctrl+滚轮、适应窗口；人员/设备可紧凑展示，左栏可拖动调整宽度 |
| 自定义分组与泳道 | 命名、改色、折叠；泳道组内或跨组拖动；整组连同内容一起排序 |
| 动作编辑 | 单击选中，双击改标题，右键编辑详情；拖动移动，边缘拉伸时长 |
| 对齐提醒 | 移动与拉伸时显示虚线时间参考线和目标泳道提示 |
| 框选与批量调整 | 空白拖框多选；整体移动时间/泳道，整体等比例拉伸 |
| 关键动作 | 单个或批量添加金色星标，保留在项目文件及导出中 |
| 前后依赖 | 右节点 → 左节点表示前置结束后开始；可启用后续动作自动顺延 |
| 同时开始 / 结束 | 左左连接同步开始，右右连接同步结束，拖动与改时长继续保持约束 |
| 关联 / 目标 | 上下节点连接只表达关系，不参与排期 |
| 连线显示与标注 | 默认无文字；双击添加标注；短线自适应，长线竖段可从动作下方穿过，横段避让 |
| 复制粘贴 | Ctrl+C/V 在鼠标位置粘贴，保留相对布局和内部关系，移除外部关系 |
| 里程碑与排练 | 零时长里程碑；相对计时、暂停、归零和进度红线 |
| 保存与恢复 | Markdown 本地存储、保存状态与冲突提示；视图内最多 60 次撤销快照 |
| 文件交换 | 完整 JSON / Markdown、AI 修改预览与导入为新项目；CSV 排程表、SVG 矢量图 |

## 四种连接，如何选择

| 连接方式 | 含义 | 是否影响排程 |
|---|---|---|
| A 右 → B 左 | A 完成后，B 才能开始 | 开启「依赖顺延」时自动推后；关闭时由用户检查冲突 |
| A 左 ↔ B 左 | A 与 B 同时开始 | 始终保持同步约束 |
| A 右 ↔ B 右 | A 与 B 同时结束 | 始终保持同步约束 |
| 上/下节点 → 上/下节点 | 关联、目标或配合关系 | 仅用于展示 |

同步线使用橙色与双端菱形；关联线为虚线；依赖线为实线。鼠标移入或选中动作时四个节点亮起。无法满足的同步/依赖约束会拒绝修改，详见 [连线与排程](docs/USER_GUIDE.md#connections)。

## 示例与 AI 工作流

[示例 Markdown 项目](examples/无人机空地协同演示.md) 可放入知识库的项目目录后打开；[完整 AI 项目包](examples/AI优化项目.cueflow.json) 可通过「导入 / 导出 → 导入项目文件」载入。

推荐流程：**编排原方案 → 导出完整项目并填写优化目标 → 交给 AI → 导入并比较变化 → 保存为新项目 → 人工排练确认。** 完整文件保留分组、泳道、动作、备注、依赖、同步、关联、标注、关键星标和项目正文。CSV 用于排程表，继续编辑或 AI 往返请使用完整项目文件。

## 支持范围与数据

| 项目 | 当前说明 |
|---|---|
| 插件版本 | 0.10.0 |
| Obsidian | manifest 声明最低 1.5.0；本轮实测 Windows / Obsidian 1.14.4 |
| 平台 | 桌面端；macOS / Linux 未完成同等客户端验收；不支持移动端 |
| 项目数据 | 格式 5；旧项目可读取，保存后使用格式 5 |
| 可移植包 | `cueflow.project` / 1，JSON 或 Markdown |
| 导入上限 | 5 MB、3000 动作、500 泳道、关联与同步连线合计 10000 条；上限不代表已验证的日常容量 |
| 开源许可 | [MIT](LICENSE) |

排程保存为知识库内的 Markdown；显示偏好保存在插件配置中。插件不内置远程 AI 调用或遥测上传。选择外部 AI、云盘或知识库同步服务时，由用户决定分享哪些文件。

当前用于桌面端、单人本地编排与人工排练。帧级/毫秒级时间、多人实时编辑、设备自动控制不在当前功能内。同泳道重叠会提示，但最终资源可行性需人工核对。v0.10.0 已通过相关本地检查及 23 项客户端增量检查，未进行全量回归；详见 [验收记录](docs/VALIDATION.md)。
